และ Hybrid POA-PSO  
ผลการวิเคราะห์ข้อมูลพบว่า ค่าที่ได้จากเซนเซอร์โดยตรงมีค่าความคลาดเคลื่อนสูง โดยมีค่า  
MAE เท่ากับ 9.7372 เซนติเมตร และค่า RMSE เท่ากับ 12.5510 เซนติเมตร ภายหลังจากการหาค่าที่

Abstract  
This project presents an optimization approach to address the accuracy limitations  
of the HC-SR04 ultrasonic sensor, which frequently encounters distance measurement  
errors. The objective is to reduce errors and compare the performance of a Hybrid  
Algorithm combining the Particle Swarm Optimization (PSO) and Pelican Optimization  
Algorithm (POA) for parameter tuning to minimize sensor discrepancies. This hybrid  
algorithm leverages the strengths of POA in global exploration to prevent entrapment  
in local optima, while utilizing PSO for local exploitation to achieve the highest precision.  
During the experimental procedure, the system employs an ESP32 microcontroller  
to acquire readings from the HC-SR04 sensor by measuring reflection distances against  
a metal tank within a range of 2 to 400 cm. The initial distance data measured prior to the  
experiment is processed against the actual distances to calculate the Mean Absolute Error  
(MAE) and Root Mean Square Error (RMSE). Subsequently, the data undergoes optimization  
using the PSO, POA, and Hybrid POA-PSO algorithms.  
The data analysis results indicated that before optimization, the sensor exhibited  
high discrepancies, with an MAE of 9.7372 cm and an RMSE of 12.5510 cm. Following the  
optimization, the Hybrid POA-PSO algorithm demonstrated maximum efficiency,  
successfully reducing the MAE to merely 2.0969 cm, which is equivalent to an error  
reduction of 78.47%. This outcome proved superior to the application of single algorithms  
such as PSO (MAE = 2.0970 cm) and POA (MAE = 2.0980 cm).
