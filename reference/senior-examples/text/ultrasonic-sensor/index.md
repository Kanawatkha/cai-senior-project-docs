# แผนที่รายงานรุ่นพี่: การเพิ่มประสิทธิภาพการวัดของเซนเซอร์อัลตราโซนิกโดยใช้อัลกอริทึมเมตาฮิวริสติก

> **เอกสารอ้างอิงภายใน (อ่านอย่างเดียว)** ใช้ดู**ลำดับและวิธีอธิบาย**เท่านั้น **ห้ามคัดลอกถ้อยคำลงงานของเรา** (คู่มือ หน้า 19) ไฟล์นี้เป็นบทสรุปที่ผมเขียนจากการอ่านข้อความทั้งเล่ม ภาพที่เปิดดูจริงมีเฉพาะปก รูปที่ 5, 6, 8, 11, 12, 13, 14 และสมการทั้ง 12 สมการ ภาพอื่นอาศัยคำบรรยายใต้ภาพ

**ตัวเล่ม:** รายงานฉบับ**เต็ม 5 บท** ของโครงงานวิศวกรรมคอมพิวเตอร์และปัญญาประดิษฐ์ 2 (รหัส 1321306) ปีการศึกษา 2568 ที่ปรึกษา ผศ.ดร. ติณณภพ ดินดำ ผู้จัดทำ 2 คน ลงวันที่กิตติกรรมประกาศ 25 พฤษภาคม 2569 ความยาว 58 หน้า PDF (เนื้อหาเลขหน้า 1-47) มีรูป 18 รูป ตาราง 3 ตาราง สมการ 12 สมการ แหล่งอ้างอิง 23 รายการ

**ลักษณะงาน:** โครงงานเชิงวิจัย/ทดลอง ปรับแก้ค่าที่วัดได้จากเซนเซอร์ HC-SR04 ด้วยสมการพหุนามกำลังสอง โดยใช้อัลกอริทึมหาค่าเหมาะสม 3 แบบ (PSO, POA และ Hybrid POA-PSO) เปรียบเทียบด้วยค่า MAE และ RMSE ต่างจากเล่ม thai-dance-web ที่เป็นระบบซอฟต์แวร์ เล่มนี้มี**สมการ ตัวเลขผลลัพธ์ กราฟเปรียบเทียบ และการอ้างอิงในเนื้อหา**ชัดเจน เหมาะเป็นแบบสำหรับโครงงานที่ต้องวิเคราะห์และเปรียบเทียบอัลกอริทึม

**ข้อควรระวังเมื่อเทียบกับงานภาค 1 ของเรา:** เล่มนี้เป็นฉบับสมบูรณ์ ใช้เป็นแบบได้เฉพาะบท 1-3 บทที่ 3 เขียนเป็นสิ่งที่ "ทำแล้ว" ส่วนบท 4-5 ไว้ใช้ภาค 2

### บทที่ 2 เอกสารและงานวิจัยที่เกี่ยวข้อง (หน้า 6-17): 6 หัวข้อ

บทนี้ต่างจากเล่ม thai-dance-web คือเป็นบท**ทฤษฎีของสิ่งที่ใช้** ไม่ใช่การรีวิวงานวิจัยทีละชิ้น (งานวิจัยเฉพาะเรื่องอยู่ใน 1.1 และ 2.5)

- **ย่อหน้านำ:** บอกวัตถุประสงค์ของบท → "แบ่งเป็น 6 หัวข้อหลัก ประกอบด้วย" + ลิสต์เลข 6 ข้อ → ย่อหน้าปิดว่าการทบทวนนี้ช่วยอะไรต่อการพัฒนา
- **2.1 ทฤษฎีคลื่นเสียงและอัลตราโซนิก:** อธิบายหลักฟิสิกส์ + สมการความเร็วเสียงเทียบอุณหภูมิ + ตารางที่ 2 ความเร็วเสียงในตัวกลางต่าง ๆ + การสะท้อน + การประยุกต์ใช้
- **2.2 HC-SR04:** รูปที่ 1 + สมการ (2.1) ระยะทาง + 2.2.1 องค์ประกอบ 2.2.2 หลักการทำงาน 2.2.3 ESP32 pinout (รูปที่ 3) 2.2.4 Arduino IDE
- **2.3 Metaheuristic Algorithms:** 2.3.1 PSO (2.3.1.1 กลไกพื้นฐาน, 2.3.1.2 ข้อดีและข้อจำกัด) 2.3.2 POA ย่อหน้ายาวอธิบายสองระยะ (Exploration/Exploitation)
- **2.4 Huber Loss:** ปัญหา (outliers, MSE, MAE) → ทางแก้ → สมการ (2.2) → อธิบาย 2 ช่วงเป็นลิสต์
- **2.5 แนวทางปรับแก้ด้วยพหุนามและ Huber:** รูปที่ 4 กราฟความคลาดเคลื่อนก่อนปรับ → สรุป 2 ลักษณะเด่น (ไม่เป็นเชิงเส้น, มี outliers) → อ้างงานวิจัย (Aliew 2022) [18, 19] → ทำไมต้องใช้ Huber ร่วมกับพหุนาม
- **2.6 ค่าสถิติที่ใช้วัด:** MAE (2.3) และ RMSE (2.4) พร้อมบล็อก "โดยที่" นิยามตัวแปรทีละบรรทัด

### บทที่ 4 ผลการศึกษาและอภิปรายข้อมูล (หน้า 34-40): 3 หัวข้อ

บทสั้น 7 หน้า แต่มีตัวเลขและกราฟเป็นแกน

**แม่แบบการอภิปรายกราฟ (ใช้ซ้ำ 4.2.1-4.2.3 มีประโยชน์ต่อบท 4 ของภาค 2):** รูป + คำบรรยาย → "จากการพิจารณากราฟภาพที่ N ซึ่งแสดงความสัมพันธ์ระหว่าง X กับ Y สามารถอภิปรายผลได้ดังต่อไปนี้" → ย่อหน้าต่ออัลกอริทึมแต่ละตัว ("อัลกอริทึม PSO (กราฟย่อยด้านซ้าย) แสดง...") ทุกย่อหน้าบอก **สังเกตเห็นอะไร + มีตัวเลข/ช่วงรอบที่ชัดเจน + ตีความว่าสะท้อนอะไร**

**ภาพที่เปิดดูแล้ว:** รูปที่ 14 เป็นกราฟย่อย 3 กราฟเรียงแนวนอน (PSO, POA, Hybrid) แกนตั้งคือ Fitness (Huber loss) แกนนอนคือรอบ ลู่เข้าใกล้ 7.0 ทั้งสาม Hybrid มีเส้นประแนวตั้งที่รอบ 151 ระบุจุดสลับจาก POA ไป PSO

## รูปแบบการเขียนที่สังเกตได้ (ใช้เป็นแนวทาง ไม่ต้องลอกถ้อยคำ)

- **หัวข้อ:** ระดับ 1.1 ตัวหนา ระดับ 1.3.1/2.2.1 ตัวธรรมดา (ใช้เป็นป้ายนำบรรทัด) ชื่อบทสองบรรทัด ("บทที่ N" / ชื่อบท) กึ่งกลาง ตัวหนา
- **การอ้างอิงในเนื้อหา:** ใช้ตัวเลขในวงเล็บเหลี่ยม [n] ท้ายประโยคหรือท้ายย่อหน้า มีทั้งบทที่ 1, 2, 4 ต่างจากเล่ม thai-dance-web
- **สมการ:** กึ่งกลางหน้า เลขสมการชิดขวา "(บท.ลำดับ)" เช่น (2.1) (3.4) ตามด้วยบล็อก "โดยที่" นิยามตัวแปรทีละบรรทัด และมีประโยคนำ "ดังสมการที่ (N)" ก่อนสมการ
- **ภาพ/ตาราง:** คำบรรยายรูปอยู่ใต้ภาพ ("รูปภาพที่ N ..." ชื่อ "รูปภาพที่ N" ตัวหนา) ส่วนตาราง ชื่อ "ตารางที่ N ..." อยู่เหนือตาราง ตัวหนา หมายเลขนับต่อเนื่องทั้งเล่ม (บางจุดในเนื้อหาเขียน "ภาพที่ N" สลับกับ "รูปภาพที่ N")
- **ศัพท์เทคนิค:** ภาษาไทยปนอังกฤษ ในวงเล็บเมื่อกล่าวครั้งแรก เช่น "ฟังก์ชันการสูญเสียฮิวเบอร์ (Huber Loss Function)"
- **ลิสต์:** ลิสต์เลข (1., 2.) และจุดนำหน้า (•) พิมพ์เป็นข้อความเอง
- **เลขในเนื้อหา:** ผลลัพธ์รายงานเป็นตัวเลขชัดเจน (ทศนิยม 4 ตำแหน่ง) พร้อมร้อยละการลดลง

## จุดที่ใช้ได้กับงานภาค 1 ของเรา (บท 1-3)

- **บท 1:** ลำดับของ 1.1 ในเล่มนี้ (บริบท → ข้อจำกัดของสิ่งที่มี → งานที่ผ่านมา → ช่องว่าง → ข้อเสนอ → ความสำคัญ) เป็นโครงที่ชัดและมีการอ้างอิงในตัว เหมาะกับหัวข้อที่ต้องการเหตุผลเชิงวิชาการ
- **บท 2:** เลือกใช้แม่แบบรีวิวงานวิจัยของ thai-dance-web ร่วมกับบล็อก "โดยที่" นิยามตัวแปรของเล่มนี้ ถ้างานของเรามีสมการ
- **บท 3:** ลำดับ "ข้อมูล → แบบจำลองทางคณิตศาสตร์ → อัลกอริทึม → workflow ทีละส่วน (รูป flowchart + ลิสต์ขั้นตอน) → เครื่องมือ" ของเล่มนี้ใช้เป็นโครงได้ และแนวคิดให้ทุก workflow มี "รูป + ขั้นตอนเลข" ทำให้อ่านง่าย
