## ลำดับหน้าของเล่ม (ส่วนนำ)

1. ปกนอก: โลโก้ PIM กึ่งกลางด้านบน → ชื่อโครงงานไทย → ชื่อโครงงานอังกฤษ → ชื่อ-รหัสผู้จัดทำเรียงเป็นคอลัมน์ (คำนำหน้า | ชื่อ | นามสกุล | รหัส) → ข้อความล่างหน้า 5 บรรทัด ("รายงานการค้นคว้าอิสระนี้ เป็นส่วนหนึ่งของการศึกษาตามหลักสูตร / ปริญญา... / คณะ... สถาบัน... / ปีการศึกษา / ลิขสิทธิ์เป็นของ...") ตัวหนาทั้งหมด จัดกึ่งกลาง (ดูภาพปกจริง)
2. ปกใน (ไทย) เหมือนปกนอก
3. ปกใน (อังกฤษ) มีโลโก้ ข้อความ "A Senior Project Submitted in Partial Fulfillment of the Requirements For the Degree of Bachelor of Computer Engineering ..."
4. หน้าอนุมัติ: เรื่อง / ผู้จัดทำ / อาจารย์ที่ปรึกษา / คณะ / สาขาวิชา → ข้อความ "รายงานการศึกษาอิสระเล่มนี้ได้รับความเห็นชอบ..." → ช่องลงนามคณบดี ประธานกรรมการ และกรรมการ
5. หน้าข้อมูลโครงงาน (เรื่อง / ผู้พัฒนา / ที่ปรึกษา / คณะ / สาขา / ปีการศึกษา) + **บทคัดย่อภาษาไทย** (ย่อหน้าเดียวยาว)
6. หน้าข้อมูลภาษาอังกฤษ (Title / Author / Advisor / Degree / Academic Year) + **Abstract** (3 ย่อหน้า)
7. **กิตติกรรมประกาศ** (ไม่มีคำนำ) ลงท้าย "ด้วยความเคารพ / คณะผู้จัดทำ / วันที่"
8. สารบัญ → สารบัญรูปภาพ → สารบัญตาราง (แต่ละอันมีหัวคอลัมน์ "เรื่อง/ภาพที่/ตารางที่" และ "หน้าที่")

### บทที่ 3 วิธีการดำเนินงาน (หน้า 11-23): 6 หัวข้อ

บทเริ่มด้วยย่อหน้านำ 1 ย่อหน้าสรุปแนวทางทั้งหมด (เทคโนโลยีหลักและการแบ่งขั้นตอน) แล้วลงท้ายว่า "...แบ่งขั้นตอนการดำเนินงานดังนี้" ทุกหัวข้อหลักขึ้นต้นด้วยย่อหน้ากรอบความคิดก่อนลงหัวข้อย่อย

| หัวข้อ | โครงที่ใช้ |
|---|---|
| 3.1 กำหนดสภาพแวดล้อมของการพัฒนา | ย่อหน้าอธิบายแนวคิดแบบผสม (Hybrid) → 3.1.1 ภาษาโปรแกรม (2 ข้อ) → 3.1.2 ไลบรารี + ตารางที่ 2 (ชื่อ/คำสั่งติดตั้ง/วัตถุประสงค์) |
| 3.2 อุปกรณ์และเครื่องมือที่ใช้ | 3.2.1 ฮาร์ดแวร์: เหตุผลที่เลือกอุปกรณ์ทั่วไป → กล้องเว็บแคม (รูปที่ 1) → ตารางที่ 3-5 สเปกคอมพิวเตอร์ 3 เครื่อง (CPU/RAM/GPU/OS) · 3.2.2 ซอฟต์แวร์ 11 รายการ (รูปที่ 2-12) แต่ละรายการ "ชื่อ + หน้าที่ในงานนี้ 1-2 ประโยค + รูปโลโก้ + คำบรรยาย" |
| 3.3 การเตรียมชุดข้อมูล | ย่อหน้านำ "แบ่งเป็น 3 ขั้นตอนหลัก" → 3.3.1 ดึงเฟรมจากวิดีโอ → 3.3.2 สกัดพิกัด (พารามิเตอร์ที่เก็บเป็นลิสต์ตัวหนา + วิธีสถิติ) → 3.3.3 คัดแยกข้อมูลและจำนวนภาพต่อเพลง (ลิสต์ซ้อนชั้น) |
| 3.4 สถาปัตยกรรมของระบบ | ย่อหน้านำอธิบายแนวคิดแบบแยกส่วน → 4 ส่วนย่อย 3.4.1-3.4.4 (รับภาพ / ประมวลผล AI / คำนวณตรรกะและคะแนน (3 โมดูล) / แสดงผล UI) |
| 3.5 กระบวนการทำงานของระบบ | 3.5.1 แผนผังภาพรวม (รูปที่ 13 flowchart) + ย่อหน้าอธิบายแผนผัง → 3.5.2 การประมวลผลด้วยกฎเกณฑ์ → 3.5.3 การแสดงผลคะแนน (รูปที่ 14) |
| 3.6 การประเมินประสิทธิภาพ | ย่อหน้านำ "แบ่งเป็น 2 ส่วน" → 3.6.1 ทดสอบความถูกต้องของตรรกะ (วิธีทดสอบ + วัดอะไร) → 3.6.2 ทดสอบประสิทธิภาพเรียลไทม์ (วัด FPS) |

**ภาพที่เปิดดูแล้ว:** รูปที่ 13 เป็น flowchart 2 ส่วน ซ้าย "การเตรียมข้อมูลและสร้างมาตรฐาน" (บันทึกวิดีโอท่ารำต้นแบบ → สกัด Landmarks ด้วย MediaPipe → คำนวณมุมด้วย Python → หาค่าเฉลี่ยมุมท่าทาง → เก็บเป็นไฟล์ JSON) ขวา "ระบบตรวจจับและประเมินผลบนเว็บ" (ผู้ใช้เปิดกล้องผ่าน Web App → สกัด Landmarks แบบเรียลไทม์ → เปรียบเทียบมุมผู้ใช้กับ JSON → ถ้าไม่ผ่านเกณฑ์ ระบบวิเคราะห์จุดที่ผิดและสร้างคำแนะนำ → แสดงคะแนนและ Feedback บน UI) ใต้แผนผังมีย่อหน้าอธิบายภาพ 1 ย่อหน้าเสมอ

- **คำเปิดประโยคที่ใช้บ่อย:** "ในโครงงานนี้...", "ผู้จัดทำได้...", "ระบบสามารถ...", "เพื่อ...", "โดย...", ปิดย่อหน้านำด้วย "ดังนี้" แล้วตามด้วยรายการ
- **ศัพท์เทคนิค:** เขียนภาษาไทยก่อน ตามด้วยอังกฤษในวงเล็บเมื่อกล่าวครั้งแรก เช่น "ปัญญาประดิษฐ์ (Artificial Intelligence: AI)" และเขียนทับศัพท์ล้วนในบางตอน
- **ภาพ:** คำบรรยาย "รูปภาพที่ N ..." อยู่**ใต้ภาพ** ส่วน **ตาราง:** "ตารางที่ N ..." อยู่**เหนือตาราง** ขนาดเล็กชิดซ้าย เลขรูปและตารางนับต่อเนื่องทั้งเล่ม (รูป 1-32, ตาราง 1-11) ไม่เริ่มใหม่ในแต่ละบท
- **ตาราง:** เส้นตารางครบ หัวตารางตัวหนา
- **ลิสต์:** ใช้ลิสต์เลข (1., 2.) และจุดนำหน้า (• และ o ซ้อนชั้น) อย่างอิสระ
- **ย่อหน้าอธิบายภาพ:** มักตามหลังภาพสำคัญ (flowchart ภาพหน้าจอ) เพื่อบอกว่าภาพแสดงอะไร

## จุดที่ใช้ได้กับงานภาค 1 ของเรา (บท 1-3)

- **บท 1:** ใช้ลำดับ 1.1 ความเป็นมา → 1.2 วัตถุประสงค์ → 1.3 ขอบเขต → 1.4 ประโยชน์ที่คาดว่าจะได้รับ → 1.5 นิยามศัพท์ได้ ข้อ 1.1 เรียงจากปัญหาใหญ่ → ปัญหาย่อย → โอกาสจากเทคโนโลยี → ช่องว่างที่งานเราเติม และ 1.3 แยกขอบเขตตามมิติเป็นแนวที่ชัดเจน
- **บท 2:** ใช้แม่แบบ 5 ส่วนของงานวิจัยแต่ละชิ้น (ชื่อ-สรุป / ข้อดี / ข้อจำกัด / ความเชื่อมโยง) จะได้บทที่โยงถึงงานเราชัดเจน แต่ควรเพิ่มการอ้างอิงในเนื้อหาตามคู่มือ
- **บท 3:** ใช้การแบ่ง "สภาพแวดล้อม → อุปกรณ์ → ข้อมูล → สถาปัตยกรรม → ลำดับการทำงาน → การประเมิน" เป็นโครงได้ และ flowchart ภาพรวมระบบเป็นรูปที่เล่มนี้ใช้ได้ผลดี
