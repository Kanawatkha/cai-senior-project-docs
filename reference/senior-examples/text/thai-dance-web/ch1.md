# บทที่ 1 บทนำ

## 1.1 ความเป็นมาและความสำคัญของปัญหา

ปัญหาและความท้าทายในการถ่ายทอดศิลปวัฒนธรรม ในปัจจุบัน ศิลปวัฒนธรรมไทย โดยเฉพาะ “รำวงไทย” ซึ่งเป็นศิลปะการแสดงที่งดงามและสะท้อนเอกลักษณ์ของชาติ ยังคงเผชิญกับความท้าทายในการถ่ายทอดและอนุรักษ์ให้คงอยู่ในสังคมยุคดิจิทัล โดยเฉพาะในกลุ่มชาวต่างชาติและผู้ที่มีความสนใจแต่ขาดโอกาสในการเข้าถึงอย่างจริงจัง

ปัญหาสำคัญประการแรก คือ การขาดแคลนโอกาสในการเรียนรู้จากผู้เชี่ยวชาญด้านนาฏศิลป์โดยตรง การฝึกรำวงไทยแบบดั้งเดิมมักต้องอาศัยการเรียนการสอนแบบตัวต่อตัวหรือในชั้นเรียนเฉพาะทาง ซึ่งมีข้อจำกัดทั้งด้านสถานที่ เวลา และจำนวนผู้เรียนที่ครูสามารถดูแลได้อย่างทั่วถึง เมื่อผู้เรียนเพิ่มมากขึ้น ย่อมส่งผลให้คุณภาพในการสอนและการแก้ไขรายบุคคลลดลง

ประการที่สอง คือ ปัญหาของผู้เรียนที่ไม่มีพื้นฐานด้านนาฏศิลป์ โดยเฉพาะผู้ที่ฝึกด้วยตนเองจากสื่อวิดีโอ ซึ่งมักเกิด “ความผิดเพี้ยนของท่ารำ” ได้ง่าย เนื่องจากไม่มีการตรวจสอบหรือแก้ไขจากผู้สอนในขณะฝึก ส่งผลให้การรำขาดความถูกต้องตามหลักนาฏศิลป์ และอาจทำให้เกิดการจดจำท่าที่ผิด ซึ่งยากต่อการแก้ไขในภายหลัง การมีครูผู้สอนส่วนตัวแม้จะช่วยได้ แต่ก็มีข้อจำกัดด้านค่าใช้จ่ายและเวลา ทำให้ไม่สะดวกสำหรับผู้เรียนส่วนใหญ่

โอกาสจากความก้าวหน้าทางเทคโนโลยี ด้วยความก้าวหน้าของเทคโนโลยีปัญญาประดิษฐ์ (Artificial Intelligence: AI) และการประมวลผลภาพคอมพิวเตอร์ (Computer Vision) ในช่วงไม่กี่ปีที่ผ่านมา ได้เปิดโอกาสใหม่ในการพัฒนาเครื่องมือช่วยฝึกฝนศิลปะการแสดงอย่างมีประสิทธิภาพ โดยเฉพาะเทคนิค Human Pose Estimation (HPE) ซึ่งเป็นเทคนิคที่สามารถระบุตำแหน่งข้อต่อสำคัญของร่างกายและมือ (Keypoints) ได้อย่างแม่นยำและรวดเร็วแบบเรียลไทม์ เทคโนโลยีนี้ถือเป็นหัวใจสำคัญที่ช่วยลดช่องว่างระหว่างการเรียนรู้ด้วยตนเองกับการฝึกสอนโดยครูผู้เชี่ยวชาญ

ในปัจจุบัน AI ถูกนำมาใช้ในงานวิเคราะห์ท่าทางมนุษย์หลากหลายด้าน เช่น การฝึกกีฬา การทำกายภาพบำบัด และการฝึกโยคะ ซึ่งแสดงให้เห็นถึงศักยภาพในการเป็นเครื่องมือช่วยประเมินผลการเคลื่อนไหว และให้คำแนะนำเพื่อปรับปรุงท่าทางได้อย่างมีประสิทธิภาพ หากเทคโนโลยีดังกล่าวถูกนำมาประยุกต์ใช้กับการเรียนรู้รำวงไทย ก็จะช่วยให้ผู้เรียนสามารถฝึกฝนได้อย่างถูกต้อง แม่นยำ และเข้าถึงได้ทุกที่ทุกเวลา

## 1.2 วัตถุประสงค์ของโครงงาน

เพื่อพัฒนาระบบตรวจจับท่ารำพื้นฐานแบบเรียลไทม์ โดยใช้เทคโนโลยี MediaPipe Pose และ MediaPipe Hands เพื่อใช้ในการตรวจสอบความถูกต้องของท่ารำจากตำแหน่งข้อต่อร่างกายและมือ เพื่อพัฒนาตรรกะการให้คำแนะนำ (Correction Logic) ที่สามารถวิเคราะห์ความผิดพลาดของท่าทางจากมุมข้อต่อ และแสดงผลคำแนะนำในการปรับแก้ท่ารำแก่ผู้ใช้งานได้แบบเรียลไทม์ เพื่อพัฒนาเว็บแอปพลิเคชันสำหรับการฝึกท่ารำพื้นฐาน ที่มีการออกแบบส่วนติดต่อผู้ใช้ (UX/UI) ให้ใช้งานง่าย มีความน่าสนใจ และรองรับผู้ใช้งานชาวต่างชาติ

## 1.3 ขอบเขตของโครงงาน

1.3.1 ด้านฟังก์ชัน (Functionality)

1. ระบบสามารถตรวจจับและประเมินความถูกต้องของท่ารำพื้นฐานจำนวน 3 เพลง ได้แก่

1.1 เพลงดอกไม้ของชาติ

1.2 เพลงคืนเดือนหงาย

1.3 เพลงรำซิมารำ

2. ระบบสามารถตรวจจับตำแหน่งข้อต่อของร่างกายและมือของผู้ใช้งานแบบเรียลไทม์ผ่านกล้องเว็บแคม
3. ระบบสามารถเปรียบเทียบท่าทางของผู้ใช้งานกับท่ามาตรฐานต้นแบบที่จัดเก็บไว้ภายในระบบ
4. ระบบสามารถคำนวณค่าความถูกต้องของท่ารำในรูปแบบเปอร์เซ็นต์ ตั้งแต่ 0 – 100
5. ระบบสามารถแสดงผล Feedback แบบเรียลไทม์ ในรูปแบบข้อความ เพื่อแจ้งจุดที่ต้องปรับปรุงของผู้ใช้งาน
6. ระบบสามารถตรวจสอบแยกตามส่วนของร่างกาย ได้แก่ การตรวจสอบท่ามือ การตรวจสอบลำตัวช่วงบนของร่างกาย และ การตรวจสอบภาพรวมของท่าทาง
7. ระบบสามารถเล่นวิดีโอต้นฉบับ และ รูปภาพประกอบการฝึกท่ารำของผู้ใช้งานได้

1.3.2 ขอบเขตด้านเทคโนโลยี (Technological Scope)

1. ใช้โมเดล MediaPipe Pose สำหรับการตรวจจับข้อต่อร่างกาย (Body Landmarks)
2. ใช้โมเดล MediaPipe Hands สำหรับการตรวจจับข้อต่อนิ้วมือ (Hand Landmarks)
3. พัฒนาบน Web Application โดยใช้ภาษา JavaScript ร่วมกับ React Framework ในการพัฒนา Frontend ของระบบ
4. ใช้ Tailwind CSS สำหรับออกแบบและจัดการส่วนติดต่อผู้ใช้งาน (UI)
5. ใช้ภาษา Python ในการประมวลผลข้อมูลตำแหน่งข้อต่อ และคำนวณค่าเฉลี่ยของมุมข้อต่อร่างกายและมือ เพื่อนำไปใช้เป็นข้อมูลอ้างอิงในการประเมินความถูกต้องของท่ารำ
6. ใช้โครงสร้างข้อมูลแบบ JSON สำหรับจัดเก็บข้อมูลท่ารำมาตรฐานและเงื่อนไขการประเมินผล
7. ระบบแบ่งการประมวลผลออกเป็นหลายส่วน ได้แก่ การตรวจสอบมือ (check_hands), การตรวจสอบลำตัว (check_body) และ การตรวจสอบภาพรวมของร่างกาย (check_allpose)

1.3.3 ด้าน UX/UI และภาษา (In terms of UX/UI and language.)

1. ระบบออกแบบให้ผู้ใช้งานสามารถเรียนรู้ท่ารำผ่านการแสดงผลแบบเรียลไทม์
2. ใช้การแสดงผลแบบ Skeleton Overlay เพื่อเปรียบเทียบท่าทางของผู้ใช้งานกับท่ารำต้นแบบ
3. มีการแสดงข้อความ Feedback เพื่อช่วยให้ผู้ใช้งานสามารถแก้ไขท่าทางได้ทันที
4. พัฒนาให้รองรับ ภาษาอังกฤษ สำหรับผู้เรียนต่างชาติ

1.3.4 ด้านข้อจำกัดสภาพแวดล้อม (Environmental Constraints)

1. ผู้ใช้งานต้องอยู่ในพื้นที่ที่มีแสงสว่างเพียงพอ เพื่อให้ระบบสามารถตรวจจับข้อต่อของร่างกายและมือได้อย่างแม่นยำ
2. ผู้ใช้งานควรอยู่ในพื้นที่เปิดโล่ง และไม่มีวัตถุบดบังร่างกายหรือมือของผู้ใช้งาน
3. พื้นหลังในการใช้งานควรเป็นพื้นหลังเรียบ และไม่มีวัตถุรบกวนภายในมุมกล้อง
4. กล้องที่ใช้งานควรสามารถมองเห็นร่างกายของผู้ใช้งานได้ครบตามส่วนที่ระบบต้องใช้ในการวิเคราะห์
5. ประสิทธิภาพของระบบอาจลดลงในกรณีที่แสงน้อย การเคลื่อนไหวเร็วเกินไป หรือมีการบังข้อต่อของร่างกาย

1.3.5 สถาปัตยกรรมโมเดล AI แบบผสมผสาน (Hybrid Architecture)

## 1.4 ประโยชน์ที่คาดว่าจะได้รับจากโครงงาน

1.4.1 เพื่อให้ชาวต่างชาติและผู้ที่สนใจสามารถเรียนรู้และฝึกฝนการรำวงมาตรฐานของไทยได้อย่างถูกต้องตามหลักนาฏศิลป์ไทย ผ่านระบบวิเคราะห์ท่าทางที่มีความเข้าใจง่ายและสามารถแสดงผลการประเมินได้แบบเรียลไทม์

1.4.2 เพื่อเป็นแนวทางในการพัฒนาและต่อยอดสู่แอปพลิเคชันด้านการเรียนการสอนศิลปวัฒนธรรมไทยในรูปแบบดิจิทัล ซึ่งสามารถประยุกต์ใช้กับศิลปะแขนงอื่น ๆ ได้ในอนาคต

1.4.3 เพื่อส่งเสริมการอนุรักษ์และเผยแพร่วัฒนธรรมไทยสู่ระดับสากล ผ่านเทคโนโลยีสมัยใหม่ที่ช่วยให้ผู้เรียนสามารถเข้าถึงการเรียนรู้ได้อย่างสะดวก ทุกที่ ทุกเวลา

## 1.5 นิยามศัพท์เฉพาะ

1.5.1 Artificial Intelligence (AI) เทคโนโลยีที่ทำให้คอมพิวเตอร์สามารถเลียนแบบกระบวนการคิด การมองเห็น และการตัดสินใจของมนุษย์ได้ โดยเฉพาะการประมวลผลภาพและการวิเคราะห์ท่าทางในงานนี้

1.5.2  Computer Vision สาขาหนึ่งของ AI ที่ทำให้คอมพิวเตอร์สามารถ “มองเห็น” และ “เข้าใจ” ภาพหรือวิดีโอ เช่น การตรวจจับร่างกาย การระบุท่าทาง และการวิเคราะห์การเคลื่อนไหวของผู้ใช้

1.5.3 Keypoints จุดอ้างอิงบนร่างกายมนุษย์ เช่น หัวไหล่ ศอก เข่า หรือข้อมือ ซึ่งใช้เป็นข้อมูลพื้นฐานในการคำนวณมุมข้อต่อและวิเคราะห์ความถูกต้องของท่ารำ

1.5.4 MediaPipe Pose โมเดลสำเร็จรูปจาก Google สำหรับการตรวจจับตำแหน่งข้อต่อร่างกาย (Body Landmarks) จำนวน 33 จุดแบบเรียลไทม์ เหมาะสำหรับการประเมินท่าทางการเคลื่อนไหวของร่างกายโดยรวม

1.5.5 MediaPipe Hands โมเดลตรวจจับจุดข้อต่อนิ้วมือ (Hand Landmarks) จำนวน 21 จุดต่อข้าง เพื่อใช้ในการวิเคราะห์ท่ามือของผู้เรียน ซึ่งมีความสำคัญต่อการรำไทยที่เน้นความอ่อนช้อยของนิ้วและฝ่ามือ

1.5.6 Correction Logic (Feedback System) ระบบการให้ข้อเสนอแนะโดยอัตโนมัติแบบเรียลไทม์ โดยเปรียบเทียบท่าทางของผู้เรียนกับท่ามาตรฐาน แล้วแสดงข้อความหรือภาพแนะนำการปรับแก้ท่าที่ผิด

1.5.7 Angle Analysis (การวิเคราะห์มุมข้อต่อ) การนำค่าพิกัดของ Keypoints มาคำนวณหาค่ามุมระหว่างข้อต่อต่าง ๆ เพื่อใช้ประเมินความถูกต้องและความสอดคล้องของท่ารำ

1.5.8 Web Application (เว็บแอปพลิเคชัน) โปรแกรมที่สามารถใช้งานผ่านเว็บเบราว์เซอร์โดยไม่ต้องติดตั้งบนเครื่อง เช่น เว็บไซต์ฝึกสอนรำวงไทยที่ผู้เรียนสามารถเข้าฝึกผ่านกล้องและรับ Feedback แบบเรียลไทม์

1.5.9 UX/UI (User Experience / User Interface) การออกแบบประสบการณ์และส่วนติดต่อผู้ใช้ให้ใช้งานง่าย สวยงาม และเหมาะกับกลุ่มผู้ใช้เป้าหมาย (ชาวต่างชาติ) เพื่อให้การฝึกรำมีความเข้าใจง่ายและเป็นมิตรต่อผู้เรียน

1.5.10 Computer Vision (คอมพิวเตอร์วิทัศน์) เทคโนโลยีหลักที่ใช้ในการวิเคราะห์ภาพวิดีโอ
