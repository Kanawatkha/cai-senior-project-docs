# การเขียนรายงานเชิงวิชาการ (มาตรฐาน PIM)

แหล่งที่มา: *คู่มือการเขียนรายงานเชิงวิชาการ ฉบับปรับปรุง พ.ศ. 2567* (`reference/Work_writing_guide2657.pdf`) ใช้ภายในสถาบันเท่านั้น

**หลักการของ skill นี้**
- สรุปจากคู่มือตรงตัว อ่านจากภาพครบทุกหน้า ไม่เพิ่มกฎของตัวเอง ข้อที่ไม่ใช่ของคู่มือต้องติดป้ายว่า "ไม่ใช่ข้อกำหนดของคู่มือ"
- ถ้ากฎใดไม่มีในคู่มือหรือคู่มือขัดกันเอง ให้ใช้ค่าที่สมเหตุสมผล (ตามไฟล์ที่ผู้ใช้มีอยู่หรือค่าปริยายของ Word) แล้วทำต่อ บอกสั้น ๆ เฉพาะถ้าเกี่ยวกับงานตรงหน้า **ผู้ใช้ยืนยันแล้วว่าเรื่องรูปแบบให้ยืดหยุ่น ไม่ต้องเคร่ง ไม่ต้องฟันธง** (รายการอยู่ด้านล่าง) ข้อนี้ใช้กับรูปแบบเท่านั้น ไม่รวมการแต่งแหล่งอ้างอิง ซึ่งห้ามเสมอ
- **เลขหน้า "(หน้า N)" ในทุกไฟล์คือเลขที่พิมพ์บนหน้าคู่มือ** หน้า PDF = N + 1 (ปกคู่มือคือหน้า PDF ที่ 1)
- ส่วนท้ายเล่มของคู่มือ "วิธีการตรวจและเกณฑ์การให้คะแนน" **ตั้งใจไม่นำมาไว้ใน skill นี้** (ผู้ใช้ตัดสินใจแล้ว) skill นี้เก็บเฉพาะกฎและเกณฑ์การทำรายงาน

## กฎสำคัญที่ต้องจำเสมอ

1. **โครงสร้าง 3 ส่วน** (หน้า 1-2): ส่วนนำ (ปกนอก ใบรองปก ปกใน คำนำ สารบัญ) → ส่วนเนื้อหา (บทนำ เนื้อเรื่อง บทสรุป) → ส่วนท้าย (บรรณานุกรม ภาคผนวก ถ้ามี ใบรองปกหลัง ปกหลัง)
2. **ฟอนต์ TH SarabunPSK ทั้งเล่ม** (หน้า 6): ปกและภาคผนวก 22 หนา, หัวข้อใหญ่ 20 หนา, หัวข้อย่อย 18 หนา, เนื้อหา 16 ปกติ, อ้างอิงในเนื้อหา 16 ปกติ, ชื่อและที่มาของภาพ 14
3. **เนื้อหา** (หน้า 23-25): บรรทัด 1.15, หลังย่อหน้า 6 pt, ย่อหน้าเยื้องประมาณ 8 ตัวอักษร หรือ 1 แท็บ
4. **อ้างอิง APA 7th ในทุกย่อหน้า**ที่ใช้ข้อมูลหรือความคิดของผู้อื่น (หน้า 7, 25) ย่อหน้าที่เป็นความคิดตนเองล้วน ๆ ไม่ต้องอ้างอิง และอ้างในเนื้อหากับบรรณานุกรมต้องตรงกันทั้งสองทาง
5. **เขียนด้วยสำนวนตนเอง** (หน้า 2, 6, 25) ภาษาระดับแบบแผน ไม่คัดลอก ไม่ตัดต่อ ไม่ดัดแปลงถ้อยคำเพียงเล็กน้อย
6. **บรรณานุกรมอย่างน้อย 5 แหล่ง** (หน้า 28) เรียง ก-ฮ แล้ว A-Z (ไทยก่อน)
7. **ห้ามใช้เป็นแหล่งข้อมูล** (หน้า 5): Google, Wikipedia, Blogs, Webboard, E-mail, Facebook, Kapook, Sanook, YouTube, Web Search Engine ใช้เว็บของหน่วยงานราชการ สถานศึกษา บริษัท องค์กรแทน
8. **ตัวเลขระบบเดียวทั้งเล่ม** (หน้า 6) ใช้เลขอารบิกตั้งแต่ปกจนบรรณานุกรม ส่วนนำ เช่น คำนำ ใช้อักษร ก ข ค กำกับหน้า ตามตัวอย่างหน้า 23 และ 47-49
9. **เลขหน้า** (หน้า 23, 28-29, 47-49): อยู่มุมขวาบน คำนำและสารบัญใช้ ก ข ... เนื้อหาเริ่มที่ 1 หน้าบรรณานุกรมและหน้าคั่นภาคผนวกไม่ใส่เลขหน้า
10. **ทำทั้งเล่มในไฟล์เดียว** แบ่งส่วนด้วย Section Break (หน้า 47) สร้างสารบัญจาก Heading 1-3 แล้วกด Update Table ทุกครั้งที่หัวข้อเปลี่ยน (หน้า 32-34) และทำเลขหน้าในสารบัญหลังเนื้อหาเสร็จ (หน้า 2)

## สิ่งที่คู่มือไม่ระบุ (ตรวจจากภาพครบทุกหน้าแล้ว)

- **ขนาดกระดาษและขอบกระดาษทุกด้าน** (หน้าคู่มือเป็น Letter แต่ไม่ได้บอกว่าต้องใช้ ส่วน 1.27 ซม./0.5 นิ้วในภาพหน้าจอเป็นค่าปริยายของ Word)
- ขนาดฟอนต์และตำแหน่งละเอียดของเลขหน้า เนื้อหาของหัวกระดาษ/ท้ายกระดาษ
- รูปแบบสารบัญภาพประกอบ/สารบัญตาราง
- รูปแบบชื่อตาราง เช่น "ตารางที่ 1" (ตัวอย่างหน้า 55 ของส่วนท้ายเล่มมีชื่อตารางเป็นแถวหัวตาราง)
- ขนาดของ hanging indent และฟอนต์ภาษาอังกฤษแยกจากภาษาไทย
- โลโก้บนปก: **ตัวอย่างปก (หน้า 20) ไม่มีโลโก้** ใส่โลโก้ตามที่ผู้ใช้ต้องการได้ ไม่ต้องถาม

**ค่าปริยายเมื่อต้องใช้ (ไม่เคร่ง):** ขนาดกระดาษและขอบ ใช้ตามที่ไฟล์ .docx ของผู้ใช้ตั้งไว้แล้ว ถ้ายังไม่มีใช้ค่าปริยายของ Word / รูปแบบรายการบรรณานุกรม ใช้ตัวอย่าง 7th ของคู่มือเป็นหลัก (พิมพ์เองหรือสร้างด้วยเครื่องมือ Word แล้วปรับก็ได้) / โลโก้ ตามที่ผู้ใช้ใส่ / เรื่องอื่นที่ไม่ระบุ ใช้ค่าปริยายของ Word

## ขั้นตอนเมื่อผู้ใช้ให้เขียนหรือแก้รายงาน

1. ระบุว่างานแตะส่วนไหน แล้วเปิดไฟล์ที่ตรงกับส่วนนั้น
2. เขียนหรือแก้ตามกฎ โดยใช้สไตล์ของ Word (Heading, Caption, Citation) แทนการจัดรูปแบบมือ
3. ตรวจตามรายการท้ายไฟล์นี้ก่อนส่งงานคืน
4. ถ้ากฎขัดกับไฟล์ตัวอย่างรุ่นพี่หรือไฟล์ของผู้ใช้ ให้ยึดคู่มือ แล้วแจ้งว่าต่างกันตรงไหน
5. เจอจุดที่คู่มือขัดกันหรือไม่ระบุ ให้ใช้ค่าที่สมเหตุสมผลแล้วทำต่อ บอกสั้น ๆ ถ้าเกี่ยวกับงานตรงหน้า ไม่ต้องรอผู้ใช้ตัดสิน
