# โครงสร้างรายงานและขั้นตอนการทำรายงาน

(คู่มือ หน้า 1-2 โครงสร้าง, หน้า 2-6 ขั้นตอน, หน้า 19 ข้อควรระวัง ตรวจจากภาพครบทุกหน้า เลขหน้าคือเลขที่พิมพ์ในคู่มือ หน้า PDF = เลขนั้น + 1)

รายงานเชิงวิชาการ คือผลการศึกษา ค้นคว้า รวบรวม วิเคราะห์เรื่องทางวิชาการเรื่องใดเรื่องหนึ่งด้วยตนเองอย่างมีระเบียบแบบแผน อาจมีชื่อเรียกต่างกัน เช่น รายงานการค้นคว้า รายงานวิจัย ภาคนิพนธ์ สารนิพนธ์ ปริญญานิพนธ์ วิทยานิพนธ์

## โครงสร้างพื้นฐาน 3 ส่วน

### 1. ส่วนนำ (ก่อนเนื้อเรื่อง)

| ลำดับ | องค์ประกอบ | ลักษณะ |
|---|---|---|
| 1.1 | ปกนอก | ปกหน้าเล่ม อาจใช้กระดาษสี หนาพอสมควร สีสุภาพ ระบุ: ชื่อรายงาน ชื่อผู้จัดทำ รหัสนักศึกษา ข้อมูลประกอบการทำรายงาน คณะ สถานศึกษา ภาคการศึกษา ปีการศึกษา |
| 1.2 | ใบรองปก | กระดาษเปล่า ไม่มีข้อความ 1 แผ่น (ไม่มีเส้น) |
| 1.3 | ปกใน | รายละเอียดเหมือนปกนอกทุกประการ ใช้กระดาษอ่อนเหมือนกระดาษเนื้อหา |
| 1.4 | คำนำ | คำว่า "คำนำ" อยู่บนกึ่งกลางหน้า ย่อหน้าถัดมาเขียนวัตถุประสงค์ในการทำรายงาน อาจขอบคุณผู้ช่วยเหลือ จบย่อหน้าแล้วลงชื่อผู้จัดทำที่มุมขวาล่าง |
| 1.5 | สารบัญ | คำว่า "สารบัญ" บนกึ่งกลางหน้า ถัดมาคำว่า "เรื่อง" และ "หน้า" เรียงหัวข้อทางซ้ายตั้งแต่ข้อ 1. บทนำ ไปจนถึงสรุป บรรณานุกรม ภาคผนวก (ถ้ามี) เลขหน้าเริ่มต้นของแต่ละหัวข้อทางขวา ควรทำเลขหน้าหลังเนื้อหาเสร็จ |

### 2. ส่วนเนื้อหา

| ลำดับ | องค์ประกอบ | ลักษณะ |
|---|---|---|
| 2.1 | บทนำ | ต่างจากคำนำ กล่าวถึงความเป็นมา เหตุจูงใจ อธิบายสาระคร่าว ๆ ก่อนเข้าเนื้อเรื่อง บอกปัญหา ขอบเขตการทำรายงาน (กว้างหรือแคบเพียงใด) และวิธีการศึกษาค้นคว้า |
| 2.2 | เนื้อเรื่อง | ผลการศึกษา เรียบเรียงตามหัวข้อในสารบัญ สำนวนของผู้จัดทำ ไม่คัดลอก ไม่ละเมิดลิขสิทธิ์โดยเด็ดขาด ข้อมูลจากแหล่งอื่นต้องอ้างอิงในเนื้อหา แทรกภาพ ตาราง แผนผังได้ตามเหมาะสม ต้องอ้างอิงที่มาและเรียงลำดับเลขภาพ/ตารางให้ชัดเจน |
| 2.3 | บทสรุป | สรุปผลการศึกษาทั้งหมดด้วยสำนวนตนเอง สอดคล้องกับเนื้อเรื่อง ตรงประเด็น ไม่ยกตัวอย่างอีก อาจให้ข้อเสนอแนะเพื่อแนวทางค้นคว้าต่อไป |

### 3. ส่วนท้าย

| ลำดับ | องค์ประกอบ | ลักษณะ |
|---|---|---|
| 3.1 | บรรณานุกรม | แหล่งข้อมูลที่ใช้ทำรายงาน การอ้างอิงในเนื้อหากับบรรณานุกรมต้องสอดคล้องกัน |
| 3.2 | ภาคผนวก (ถ้ามี) | ข้อมูลเพิ่มเติมที่ไม่ต้องการให้อยู่ในเนื้อเรื่อง เช่น ผลสำรวจ แบบสอบถาม สถิติ ภาพประกอบจำนวนมาก คำอธิบายเพิ่มเติม |
| 3.3 | ใบรองปกหลัง | อยู่ก่อนปกหลัง กระดาษเปล่าไม่มีข้อความ 1 แผ่น |
| 3.4 | ปกหลัง | กระดาษสีหนาพอสมควร สีสุภาพ สีหรือรูปแบบเหมือนปกนอก |

## ขั้นตอนการทำรายงาน 8 ขั้น

1. การเลือกหรือกำหนดหัวข้อ
2. การกำหนดวัตถุประสงค์
3. การเขียนโครงเรื่อง
4. การสำรวจแหล่งข้อมูลและรวบรวมข้อมูล
5. การบันทึกข้อความ
6. การเรียบเรียงรายงาน
7. การอ้างอิงในเนื้อหา
8. การเขียนบรรณานุกรม

### 1. การเลือกหัวข้อ (หน้า 3) — 4 หลักพิจารณา

1. ผู้จัดทำ**สนใจ**ในเรื่องนั้น (ความสนใจส่วนตัวช่วยให้ทำได้มีประสิทธิภาพและต่อยอดเร็ว)
2. ผู้จัดทำ**มีความรู้**เบื้องต้น รู้ว่าเนื้อหาและข้อมูลเป็นอย่างไร รู้ว่าจะสืบค้นจากที่ใด
3. **มีแหล่งข้อมูล**ค้นคว้า เช่น ห้องสมุดมหาวิทยาลัย หอสมุดแห่งชาติ อินเทอร์เน็ต สื่ออิเล็กทรอนิกส์ สัมภาษณ์ผู้เชี่ยวชาญ
4. **เหมาะสม** ไม่ใหญ่/กว้างเกินไป ไม่เล็ก/แคบเกินไป และนำผลไปใช้ประโยชน์ต่อได้

ตัวอย่างลดจากกว้างไปแคบ: การบริการ → การบริการในร้านสะดวกซื้อ → การบริการของพนักงานผลัดดึกในร้านสะดวกซื้อ

### 2. การกำหนดวัตถุประสงค์ (หน้า 3)

กำหนดจุดมุ่งหมายว่าเหตุใดทำเรื่องนี้ ต้องการศึกษาหรือรู้สิ่งใด เขียนเป็นข้อ ขึ้นต้นด้วย "เพื่อศึกษา..."

ตัวอย่างในคู่มือ: รายงานเรื่อง การบริการของพนักงานผลัดดึกในร้านสะดวกซื้อ มีวัตถุประสงค์คือ 1) เพื่อศึกษาบุคลิกลักษณะของลูกค้าช่วงผลัดดึกในร้านสะดวกซื้อ 2) เพื่อศึกษาวิธีการให้บริการของพนักงานผลัดดึกในร้านสะดวกซื้อ เพื่อนำไปสู่การพัฒนาได้อย่างมีประสิทธิภาพ

### 3. การเขียนโครงเรื่อง (หน้า 4)

โครงเรื่องที่ดี:
- ทุกหัวข้อความคิดอยู่ในขอบข่ายของชื่อเรื่อง
- ไม่ซ้ำซ้อนกัน
- มีความสำคัญเสมอกัน (หัวข้อระดับเดียวกันมีน้ำหนักใกล้กัน)
- สัมพันธ์และเชื่อมโยงกัน
- ถ้าขาดหัวข้อใด เนื้อเรื่องจะไม่สมบูรณ์

**ระบบตัวเลข**: ถ้ามีข้อ 1.1 ต้องมี 1.2 เพราะข้อย่อยอยู่เพียง 1 ข้อไม่ได้ (จะเท่ากับเป็นหัวข้อใหญ่)

```
1. ......
   1.1 ......
   1.2 ......
       1.2.1 ......
       1.2.2 ......
2. ......
   2.1 ......
   2.2 ......
```

### 4. การสำรวจแหล่งข้อมูล (หน้า 4-5)

เริ่มจากแหล่งใกล้ตัว (ผู้จัดทำมีข้อมูลเรื่องนั้นหรือไม่) แล้วค้นเพิ่มจาก:

1. **ห้องสมุด ร้านหนังสือ**: หนังสือ ตำรา เอกสาร คู่มือ แผ่นพับ โบรชัวร์
2. **อินเทอร์เน็ต**: สะดวก รวดเร็ว ข่าวสดใหม่ แต่ข้อมูลผิดพลาดง่ายและขาดความน่าเชื่อถือ ให้เลือกเว็บที่ได้มาตรฐาน เว็บหน่วยงานราชการ สถานศึกษา บริษัท องค์กร (เช่น pim.ac.th, cpall.co.th, orst.go.th)
   - **ไม่ควรใช้**: Google, Wikipedia, Blogs, Webboard, E-mail, Facebook, Kapook, Sanook, YouTube, Web Search Engine ต่าง ๆ (เปลี่ยนแปลงได้ง่ายโดยผู้ใช้ ไม่แจ้งล่วงหน้า ผิดพลาดง่าย ทำให้รายงานขาดความน่าเชื่อถือ)
3. **บุคคลผู้เชี่ยวชาญ**: ผู้มีความถนัดรอบรู้ในหัวข้อ น่าเชื่อถือหรือได้รับการยอมรับกว้างขวาง เช่น ผู้จัดการบริษัท อาจารย์ ศิลปิน

### 5. การบันทึกข้อความ (หน้า 5-6)

บันทึกเฉพาะข้อมูลสำคัญที่จะใช้ ส่วนประกอบ 3 อย่าง:

1. **หัวเรื่อง**: ประเด็นหรือโจทย์ที่จะนำมาใช้ในหัวข้อรายงาน
2. **แหล่งที่มาของเรื่อง**: ระบุละเอียดที่สุด (ผู้แต่ง ชื่อเรื่อง เล่มที่ ฉบับที่ พิมพ์ครั้งที่ จังหวัดที่พิมพ์ สำนักพิมพ์ ปีที่พิมพ์ เลขหน้า) มักเขียนในรูปแบบเดียวกับบรรณานุกรม
3. **เนื้อเรื่อง**: จดเท่าที่จำเป็นอย่างละเอียด ใช้วิธีสรุปความหรือคัดลอกความก็ได้

ถ่ายภาพด้วยมือถือแทนการจดได้ ถ้าไม่สามารถถ่ายเอกสารหรือยืมได้ แต่ต้องจดหัวเรื่องและแหล่งที่มาแนบไปด้วย และระวังไม่ให้ละเมิดลิขสิทธิ์โดยเด็ดขาด

### 6. การเรียบเรียงรายงาน (หน้า 6)

- เขียนทุกส่วนด้วยสำนวนภาษาของตนเอง
- ใช้ภาษาระดับแบบแผนอย่างถูกต้อง ระวังภาษาปาก คำซ้ำ คำสแลง คำฟุ่มเฟือย
- อาจสรุปความจากแหล่งอื่นแล้วอ้างอิงถูกต้อง เพื่อสนับสนุนความคิดตนให้น่าเชื่อถือ
- ใช้ตัวเลขระบบเดียวกันทั้งเล่ม (ถ้าใช้เลขอารบิก ใช้ตลอดตั้งแต่ปกหน้าถึงบรรณานุกรม รวมเลขหน้า)

## ข้อควรระวัง: การคัดลอกผลงานผู้อื่นอย่างไม่เหมาะสม (หน้า 19) ห้ามทำ

1. คัดลอกย่อหน้า ประโยค หรือส่วนใดส่วนหนึ่งของผู้อื่นมาโดยไม่อ้างอิง
2. คัดลอกคำพูดของผู้อื่นโดยดัดแปลงถ้อยคำเพียงเล็กน้อย
3. นำผลงานของผู้ที่เคยเรียนวิชาเดียวกันมาอ้างเป็นของตน โดยเปลี่ยนเนื้อหาเล็กน้อย
4. แปลผลงานต่างประเทศมาโดยไม่อ้างอิง
5. คัดลอกผลวิจัย สถิติ รูปภาพ ตัวเลข หรือข้อมูลใด ๆ มาโดยไม่อ้างอิง
6. คัดลอกผลงานมาแล้วปรับแก้เล็กน้อยหรือไม่ปรับเลย แล้วอ้างอิงผิดวิธี
